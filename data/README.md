# Project Data

This folder contains the dataset used for the E-Commerce Sales & Profitability Analysis project.

The data was cleaned and transformed using Power Query before analysis.

## Data Preparation

- Date standardization
- Missing-value handling
- Duplicate checking
- Data type correction
- Text standardization
- Product and customer data integration
- Validation before analysis

The dataset is used for demonstrating an end-to-end Data Analytics workflow.
