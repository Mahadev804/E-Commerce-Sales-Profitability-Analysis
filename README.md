# E-Commerce Sales & Profitability Analysis

## End-to-End Data Analytics Project

This project analyzes e-commerce sales performance, profitability, product performance, discount impact, and short-term sales forecasting.

### Tools Used

- Microsoft Excel
- Power Query
- Power BI
- DAX
- SQL
- Python / Pandas

### Project Workflow

Excel → Power Query → Data Modeling → SQL → Python/Pandas → Power BI & DAX → Business Insights

### Key Analysis

- Sales and profitability performance
- Regional and category analysis
- Product-level sales and profit analysis
- Discount impact on sales and profitability
- Daily sales forecasting
- SQL-based business analysis
- Python/Pandas product analysis
- Business insights and recommendations

### Key Business Finding

The analysis shows that higher sales volume does not necessarily mean higher profit margin. Product performance and discount strategy must be evaluated using both sales volume and profitability.

### Project Objective

To demonstrate an end-to-end, business-focused Data Analytics workflow using real-world style e-commerce data.
